# Savings — 15日账期消费看板

极简离线 PWA：每月15日开启账期，每期预算¥6,000，只需输入本期累计消费总额。

## 启用 GitHub Pages

仓库 Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。

发布地址（待 Pages 启用）：https://small-eccentric-solider.github.io/savings/

用 iPhone Safari 打开后，点击分享 → 添加到主屏幕。数据只保存在设备本地，建议定期导出 JSON 备份。

本仓库只存放程序，不存放个人消费账单。
